# LINEスタンプ制作キット

「スマホでおうち学習ラボ」のLINEスタンプ制作用フォルダです。

## GPTのイラストからスタンプを作る流れ

1. **プロンプト集を使って画像を作る** — [`prompts.md`](./prompts.md) をChatGPTにコピペして、
   キャラデザイン探索 → キャラシート固定 → スタンプ8種+メイン画像 を生成する
2. **画像を保存する** — できた画像を [`originals/`](./originals/) に次の名前で置く(jpg/webpでも可):
   - `01.png` 〜 `08.png` … スタンプ8種
   - `main.png` … 代表画像(文字なし)
   - `tab.png` … タブ用顔アップ(省略可。無ければmainから自動生成)
3. **変換する**
   ```bash
   node stamp/prepare.mjs
   ```
   背景の自動透過 → 余白トリム → LINE規格サイズへの縮小・中央配置 → 規格チェックまで自動で行い、
   [`png/`](./png/) に `01.png`〜`08.png` / `main.png` / `tab.png` を出力します。
   一部だけ置いて実行してもOK(あるものだけ変換されます)。
4. **確認する** — [`index.html`](./index.html) をブラウザで開くと、トーク画面風の背景で全スタンプをプレビューできます
5. **申請する** — [LINE Creators Market](https://creator.line.me/ja/) に `png/` の10ファイルをアップロード

### 注意

- 原画は**透過背景**が理想。白などの単色背景でも自動で抜きますが、
  **白背景+白フチ文字**の組み合わせは白フチごと消えるためNG(prompts.mdのリカバリ参照。薄い黄緑背景 `#9FE0B8` で出させると安全)
- 変換にはChrome/Chromiumが必要です。自動で見つからない環境では:
  ```bash
  CHROME_BIN="/path/to/chrome" node stamp/prepare.mjs
  ```

## ファイル構成

| パス | 内容 |
|---|---|
| `prompts.md` | GPTに渡すコピペ用プロンプト集 |
| `originals/` | GPTで作った原画を置く場所(ここに置いたものが変換対象) |
| `prepare.mjs` | 原画 → LINE規格PNG 変換スクリプト |
| `png/` | 申請用PNG(370×320 ×8 / main 240×240 / tab 96×74、全て透過・1MB以下) |
| `index.html` | プレビューページ(背景切替つき) |
| `build.mjs` + `svg/` | 旧版: SVG手描きの「ほっとけペンギン」生成スクリプト(フォールバックとして残置) |

## LINE規格メモ

- スタンプ画像: 最大370×320px / メイン: 240×240px / タブ: 96×74px
- すべてPNG・背景透過・1MB以下・偶数ピクセル
- 最小セットはスタンプ8個
