# GPTに渡すプロンプト集(LINEスタンプ用イラスト生成)

ChatGPTの画像生成でスタンプ用イラストを作るためのコピペ用プロンプト集です。
**STEP 1 → 5 の順に、できるだけ同じチャット内で**進めてください(絵柄ブレ防止のため)。

できた画像は `stamp/originals/` に `01.png`〜`08.png`, `main.png`, `tab.png` の名前で保存し、
`node stamp/prepare.mjs` を実行すると、LINE申請用の規格に自動変換されます(詳細は README.md)。

---

## STEP 1. キャラデザイン探索(新キャラ案を出す)

```
LINEスタンプ用の新しいゆるキャラのデザイン案を考えてください。
1枚の画像に候補を4案、2×2で並べて描いてください。それぞれに番号をつけてください。

条件:
- ゆるキャラのLINEスタンプ風。すっきりした太めの均一な主線+フラット塗り
- まんまるに近いシンプルなフォルム。手足は短く小さく
- やさしいパステル調の配色(真っ黒の線やビビッドな色は使わない)
- モチーフの例: ペンギン、しろくま、うさぎ、ことり、おにぎり、パン(自由に提案してOK)
- 白背景、キャラのみ(文字は入れない)
```

ピンとこなければ追い指示:

```
◯番の方向性は好きです。◯番をベースに、もう少し△△な案をあと4つ描いてください。
```

---

## STEP 2. キャラクターシート固定(絵柄の基準を作る)

案が決まったら、以後の全生成の「基準画像」になるシートを作らせます。

```
◯番のキャラに決めます。このキャラのキャラクターシートを1枚作ってください。

内容:
- 中央に正面立ち姿を大きく
- そのまわりに表情バリエーションの顔アップ4つ(にこにこ/ウインク/しょんぼり/ねむい)
- 下に使用色のカラーパレット見本を並べる
- 絵柄: 太めの均一な主線+フラット塗り、ゆるいLINEスタンプ風
- 白背景・文字なし

このシートを今後のスタンプ生成の基準にします。キャラの名前も3案ください。
```

**できたシート画像は必ず保存**してください。STEP 3以降は毎回このシートを添付します。

---

## STEP 3. スタンプ8種の生成

各スタンプ共通の頭に、下の【共通ルール】を毎回付けてください(キャラシート画像も毎回添付)。

```
添付のキャラクターシートと同じキャラ・同じ絵柄・同じ配色で、LINEスタンプ用イラストを1枚描いてください。

【共通ルール】
- 背景は必ず透過(透明背景のPNG)。背景に色や模様を入れない
- サイズ1024×1024。キャラと文字が切れないように、画像の四辺に余白を残す
- 太めの均一な主線+フラット塗り。キャラシートの配色を厳守
- セリフの文字は日本語で、画像の上部に大きく。手描き風の丸っこいかわいい文字
- 文字の色はこげ茶で、まわりに太めの白フチをつけて読みやすく
- ひらがなを正確に。誤字は禁止
```

そのあとに、作りたいスタンプの【今回の内容】を続けます:

**01 おはよう**
```
【今回の内容】
- セリフ: 「おはよう」
- ポーズ: 両手を上げて元気にばんざい、にこにこ笑顔。頭の横に小さなおひさま
```

**02 ありがとう**
```
【今回の内容】
- セリフ: 「ありがとう」
- ポーズ: にこにこしながらぺこりとおじぎ。まわりに小さなハートを2つ
```

**03 OK!**
```
【今回の内容】
- セリフ: 「OK!」
- ポーズ: 片手を上げてウインク。自信まんまんの表情
```

**04 おつかれさま**
```
【今回の内容】
- セリフ: 「おつかれさま」
- ポーズ: 湯のみを両手で持ってほっこりした表情。湯のみから湯気
```

**05 ごめんね**
```
【今回の内容】
- セリフ: 「ごめんね」
- ポーズ: 眉を下げてしょんぼり。頭の横に汗のしずくひとつぶ
```

**06 いってらっしゃい**
```
【今回の内容】
- セリフ: 「いってらっしゃい」
- ポーズ: 片手を大きく上げて笑顔で手をふる
```

**07 だいすき**
```
【今回の内容】
- セリフ: 「だいすき」
- ポーズ: 大きなハートをぎゅっと抱きしめて、うれしそうな笑顔
```

**08 おやすみ**
```
【今回の内容】
- セリフ: 「おやすみ」
- ポーズ: ナイトキャップをかぶって目を閉じ、うとうと。横に三日月と「Zzz」
```

## STEP 4. メイン画像・タブ画像

**main(ストアに表示される代表画像)**
```
添付のキャラクターシートと同じキャラ・同じ絵柄で、スタンプの代表画像を描いてください。
- 文字なし。にこにこ笑顔の正面立ち姿、横に小さなハートひとつ
- 背景は透過、1024×1024、四辺に余白
```

**tab(トーク画面の切替タブ用・省略可)**
```
添付のキャラクターシートと同じキャラ・同じ絵柄で、顔のアップだけを描いてください。
- 文字なし。にこにこ笑顔の顔アップ
- 背景は透過、1024×1024、四辺に余白
```
※ tabを作らなくても、変換スクリプトがmainから自動で縮小生成します。

## STEP 5. うまくいかない時のリカバリ

**文字が崩れた・誤字になった**
```
イラストはこのままで、セリフの文字だけ「おはよう」に正しく描き直してください。ひらがなを正確に。
```

**絵柄・配色がブレた**(キャラシートを再添付して)
```
添付のキャラクターシートと、線の太さ・目の形・配色を完全に一致させて描き直してください。
```

**背景が透過にならない**
```
背景を完全に透明にしたPNGで出力してください(市松模様の絵ではなく、本当の透過)。
```
それでも白背景でしか出ない場合は、次のように色付き背景で出させてください:
```
背景は薄い黄緑の一色(#9FE0B8)で塗りつぶしてください。キャラや文字には黄緑を使わないでください。
```
→ 変換スクリプトが背景色を自動で抜きます。
**注意: 白背景のままだと、文字の白フチまで自動除去で消えてしまいます。透過か色付き背景にしてください。**

**キャラが枠で切れた**
```
キャラと文字が切れないように少し小さくして、画像の四辺にしっかり余白を取ってください。
```
